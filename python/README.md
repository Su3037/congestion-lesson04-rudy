# Python practice: RUDY classroom proxy

1. Open `starter.py` and implement `tile_of`, `demand_p` and `overflow_metrics`.
2. Run `python3 check.py`. It prints `INCOMPLETE` until all three exist, then `PASS` or `FAIL` with the first mismatching number.
3. Compare with `rudy_ref.py` (exact fractions) only after you pass, or when stuck.

Files: `fixture.json` is the teacher's example (adapted, CC BY 4.0, Yongfu Li); `expected.json` holds the expected demand matrices and overflow metrics as fractions. Python 3.9+ standard library only.
